# For Aa, M Gilang Ramadhan

An interactive premium virtual birthday gift created especially for Aa, M Gilang Ramadhan.

This is not designed as a conventional birthday website.

It is designed as a small digital experience combining storytelling, photography, music, animation, games, realtime clocks, wishes, and a cinematic final surprise.

> Made with care, code, and a little bit of love.

---

## Project Overview

This project is a mobile-first interactive birthday gift for a long-distance relationship.

The visual direction combines:

- Premium glassmorphism
- Luxury editorial design
- Midnight blue atmosphere
- Soft romantic accents
- Cinematic transitions
- Interactive storytelling
- Lightweight 3D-inspired visual effects
- Mobile-first interaction
- Performance-conscious animation

The main concept is:

**Two places. One connection.**

The experience is built around distance, attention, communication, memories, wishes, encouragement, and celebration.

## Interactive Gift

The digital gift box is created entirely using HTML and CSS.

No external gift image is required.

Features:

- CSS 3D-style construction
- Ribbon
- Shadow
- Lighting
- Opening animation
- Interactive message
- Touch support
- Keyboard accessibility

The story section focuses on a virtual/LDR relationship.

The storytelling uses themes such as:

- Messages
- Communication
- Distance

- Waiting for replies
